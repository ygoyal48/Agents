# Holdings

Companies currently held in the portfolio. One subfolder or file per company (analysis dashboards, verdict notes, monitoring logs per strategy.md §13).

- `Docs/` — supporting documents for held companies (annual reports, quarterly results, credit rating reports, exchange filings, con-call transcripts).

Every holding is monitored per strategy.md §13 (quarterly results, shareholding/pledge, insider trades after announcements, AR-vs-exchange diffs) and §14 sell triggers.
